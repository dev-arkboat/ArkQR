Dots carry identical frames as anchored dot grids — no per-symbol error correction, so the fountain code absorbs every drop. Close range, centered captures only.

QR ink

Ink is appearance only — same data, decoded by brightness. Green is lightest; test it with your phones before relying on it.

Error correction

Same bytes, smaller QR — easier to scan at distance. Lost frames are absorbed by the fountain code, so lower correction stays safe.
